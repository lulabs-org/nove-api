> **说明：**
> 

> 自2026年01月16日起，“查询单个录制详情”接口将提升安全规范，针对新创建应用需在 Header 中携带 STS-Token 票据，以保障数据安全。
> 


## 接口描述
- **描述**：查询单个云录制的详情信息，包括录制文件和录制转写，并可获取播放地址和下载地址。
   

   > **注意：**
   > 
>   - 企业 secret 鉴权用户可获取该用户所属企业下的单个录制列表。
>   - OAuth 2.0鉴权用户只能获取该企业下 OAuth 2.0应用的单个录制列表。

- **请求方法**：GET。

- **鉴权方式**：支持 AK/SK 和 OAuth 2.0鉴权。

- **依赖权限点**：

  - 自建应用：具备**管理企业录制**、**查看企业录制**的权限。

  - 三方应用：具备**查看您的录制**、**查看和管理您的录制**权限。

  - Operator 用户角色：勾选**账户管理** > **录制管理** > **查看**权限。可前往**用户管理** > **角色管理**页面设置。

- **接口请求域名**：

   ``` Plaintext
   https://api.meeting.qq.com/v1/addresses/{record_file_id}?operator_id={operator_id}&operator_id_type={operator_id_type}
   ```

## 🎯 主要功能

### 用户与组织管理
- 用户注册、登录与密码重置
- 个人信息管理
- 组织创建与成员管理
- 部门与角色权限配置

### 会议管理
- 创建与管理会议
- 会议录制与回放
- 会议内容 AI 转写与总结
- 会议数据统计分析

### API Key 管理
- 创建与管理 API Key
- 通过 API Key 实现程序化访问
- 查看 API Key 用量统计

### AI 智能体集成
- 通过 MCP (Model Context Protocol) 连接外部 AI 工具
- AI 驱动的数据查询与分析

### 第三方平台集成
- 腾讯会议集成
- 飞书多维表格同步
- 微信小店订单同步
- 邮件通知与短信验证

## 📖 API 文档

完整的 API 文档可以通过以下方式访问：

- **Swagger UI**: 访问部署后的 `/api` 端点
- **Redoc 文档**: 访问部署后的 `/docs` 端点
- **GraphQL**: 访问部署后的 `/graphql` 端点

> 详见 [API 接口文档总览](api/index.md)

# 会议 API

会议 API 是系统的核心功能模块之一，负责管理腾讯会议等来源同步进来的会议元数据、参会人员以及大语言模型处理后生成的会议纪要和转写数据。

## 核心端点概览

| 端点 | 方法 | 说明 | 鉴权要求 |
|------|------|------|---------|
| `/meetings` | `GET` | 分页获取当前用户（或租户内）的会议列表 | 是 |
| `/meetings/:id` | `GET` | 获取指定会议的详细信息 | 是 |
| `/meetings/:id/summary` | `GET` | 获取该会议生成的 AI 摘要和纪要 | 是 |
| `/meetings/:id/transcripts` | `GET` | 获取会议的完整文本转写记录 | 是 |

> **提示**: 关于完整的请求参数 (DTO) 和响应格式，请在本地启动项目后访问 `/api` (Swagger UI) 查看详细的交互式文档。

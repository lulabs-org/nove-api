# 用户 API

用户 API 提供当前登录用户的个人资料查询、更新以及相关配置的管理功能。

## 核心端点概览

| 端点 | 方法 | 说明 | 鉴权要求 |
|------|------|------|---------|
| `/user/profile` | `GET` | 获取当前登录用户的个人档案 | 是 |
| `/user/profile` | `PATCH` | 更新个人信息（如昵称、头像） | 是 |
| `/user/settings` | `GET` | 获取用户偏好设置 | 是 |

> **提示**: 关于完整的请求参数 (DTO) 和响应格式，请在本地启动项目后访问 `/api` (Swagger UI) 查看详细的交互式文档。

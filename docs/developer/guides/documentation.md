## 🏗️ 文档结构

```
docs/
├── .vitepress/          # VitePress 站点配置与主题
├── developer/           # 开发者文档

│   ├── modules/         #   核心模块（认证、API Key、MCP）

│   └── faq/             #   常见问题
├── public/              # 静态资源（Logo 等）
└── index.md             # 站点首页
```

## 🚀 本地启动文档站点

```bash
# 在项目根目录下
pnpm docs:dev

# 或进入 docs 目录
cd docs
pnpm run docs:dev
```

构建静态站点：

```bash
pnpm docs:build
```

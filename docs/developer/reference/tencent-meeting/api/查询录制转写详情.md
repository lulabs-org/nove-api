> 


## 接口描述
- **描述**：获取云录制转写的详情，包含时间戳、文本等内容。支持 OAuth 2.0鉴权调用，仅支持授权用户为商业版、企业版、教育版。

- **依赖权限点**：

  - 自建应用：具备**管理企业录制**和**查看企业录制**权限。

  - 三方应用：具备**查看您的录制**和**查看管理您的录制**权限。

  - Operator 用户角色：勾选**账户管理 **>** 录制管理 **> **查看**权限。可前往**用户管理 **>** 角色管理**页面设置。

- **请求方式**：GET

- **接口请求域名**：

   ``` plaintext
   https://api.meeting.qq.com/v1/records/transcripts/details
   ```

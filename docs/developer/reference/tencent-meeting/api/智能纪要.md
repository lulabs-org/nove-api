## 接口描述
- **描述**：查询单个云录制的智能纪要，支持 OAuth 2.0鉴权调用，仅支持授权用户为商业版、企业版、教育版。
   

   > **注意：**
   > 

   > 当该录制文件未开启相关智能化功能或内容处于生成中状态时，不支持调用。
   > 

- **请求方法**：GET

- **鉴权方式**：AK/SK 鉴权、OAuth 2.0鉴权。

- **依赖权限点**：

  - 自建应用：具备**管理企业录制**、**查看企业录制**权限。

  - 三方应用：具备**查看您的录制**、**管理您的录制**权限。

  - Operator 用户角色：勾选**账户管理** > **录制管理** > **查看**权限。可前往**用户管理** > **角色管理**页面设置。

- **接口请求域名**：

   ``` html
   https://api.meeting.qq.com/v1/smart/minutes/{record_file_id}?operator_id_type={operator_id_type}&operator_id={operator_id}&minute_type={minute_type}&text_type={text_type}
   ```
